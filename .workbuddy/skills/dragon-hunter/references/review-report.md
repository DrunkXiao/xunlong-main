# AI 观察报告模板

AI 只解释已获取的真实数据，不虚构行情。任一字段无数据时填 `N/A` 并计入「数据完整度」。

## 字段

```
股票名称：
股票代码：
所属板块：
当前涨幅：
成交额：
换手率：
量比：
当前价格位置：        （近20日区间分位 + 相对日内高低位置）
日K趋势：             （均线排列、位置、最近3根K线形态，只描述事实）
分时强弱：            （相对昨收/均价线/大盘的表现，给数值）
大单行为：            （各档金额分布、方向占比、价格位置，不给身份结论）
逐笔成交特征：         （笔数、均笔金额、主动买卖占比、连续性）
龙虎榜情况：           （最近一次上榜日期/原因/净买入，或"近30日无记录"）
板块地位：             （板块内涨幅/成交额排名、是否为核心股）
关键支撑：
关键压力：
盘中异动：             （时间 + 事件 + 数值）
风险因素：             （数据缺口、量价背离、接近压力位、异动密度过高）
数据完整度：           （应有字段数 / 实际有值数，列出缺失项）
```

## 观察结论

只能取以下五选一：

- 强势观察
- 继续跟踪
- 等待确认
- 走势转弱
- 暂时移出观察池

每条结论必须紧跟两段：

1. **数据依据**：3–5 条，每条含具体数值与时间。
2. **不确定因素**：至少 1 条，例如「逐笔数据缺失，大单行为仅基于分钟聚合」「股价接近前高，突破未确认」。

## 硬约束

- 禁止出现：主力、机构、庄家、洗盘、出货、吸筹、必涨、目标价、建议买入/卖出。
- 禁止用「形态像」「感觉」「预计」替代数据；预测性表述必须标注为推演并给出失效条件。
- 结论与数据矛盾时以数据为准，并显式写出矛盾点。
- 数据完整度 < 60% 时不允许给出「强势观察」或「走势转弱」结论，只能「等待确认」或「继续跟踪」。

## 输出示例（片段）

```
股票名称：示例股票
股票代码：600000.SH
所属板块：银行 / 沪企改革
当前涨幅：+2.31%
成交额：15.18亿
换手率：1.42%
量比：1.86
当前价格位置：近20日区间 68% 分位；日内位于均价线上方 0.6%
日K趋势：收盘价位于 MA5/MA10 上方、MA20 下方；近3根K线两阳一阴，量能温和
分时强弱：分时涨幅 +2.31%，同期所属板块 +1.10%，相对强度 +1.21pct
大单行为：100万以上 7 笔，买 5 卖 2；累计买入 860万、卖出 320万；3 笔位于日内高位区
逐笔成交特征：共 2,341 笔，均笔 6.5万；主动买占比 57%，10:31 起连续 4 笔买入
龙虎榜情况：最近上榜 2026-11-05，原因"日涨幅偏离值达7%"，净买入 2,140万
板块地位：板块内涨幅第 3 / 42，成交额第 2
关键支撑：11.32（MA10）、11.05（前平台）
关键压力：11.96（近20日高点）
盘中异动：10:31:22 距涨停价 0.85%（P2）；10:48:05 单笔 320万主动买入
风险因素：日线仍在 MA20 下方；逐笔数据为 A 级实时，无缺口
数据完整度：19/19，无缺失

观察结论：继续跟踪
数据依据：
1. 相对强度 +1.21pct，板块内涨幅第 3、成交额第 2（10:45 快照）
2. 大单买入 860万 vs 卖出 320万，5 笔买单位于日内高位区
3. 收盘价站上 MA5/MA10，量比 1.86
不确定因素：日线未站上 MA20，突破 11.96 前高未确认；大单行为仅描述成交，不构成身份判断。
```
