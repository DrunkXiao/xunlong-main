# 运行流程与时段处理

## 盘前模式（09:00–09:25）

1. 检查各数据源连接，写 `data_source_status`（连通性、延迟、数据时间戳）。
2. 加载本地分组与上次布局，恢复选中分组。
3. 同步通达信自选股（若桥接启用），变更写 `tdx_events`。
4. 加载前一交易日行情：日K、分时快照、涨停统计。
5. 显示昨日涨停股与连板梯队（按连板高度分组）。
6. 显示热门概念与板块排名（涨幅、成交额、涨停家数）。
7. 显示新增龙虎榜记录（按 `publish_date` 降序）。
8. 生成今日重点观察清单（分组内 + 昨日涨停 + 龙虎榜 + 桥接导入，去重）。
9. 加载启用中的预警规则并预热指标（MA 等）。

盘前任何数据缺失都要在检查结果面板列出「缺失项 + 原因 + 影响的功能」，不允许静默跳过。

## 盘中模式（09:30–11:30, 13:00–15:00）

1. 订阅观察池行情（分组内去重后的并集），记录订阅数。
2. 按周期增量更新分时与 K 线，1 分钟桶聚合。
3. 数据源支持时接收逐笔，写入 `tick_history`，超出保留期的滚动归档。
4. 计算大单事件，写 `large_order_events` 并打标签。
5. 检测价格与量能异动，走预警引擎。
6. 定时（默认 60s）刷新板块与概念关联及板块涨停家数。
7. 执行预警规则，按冷却去重后通知。
8. 保存重要异动事件（P1/P2 全存，P3 采样存）。
9. 随时可切单股 / 多股，切换不重建订阅、不丢已有 K 线缓存。

盘中约束：

- 集合竞价（09:15–09:25）阶段不触发分时类预警，价格类只做记录不弹窗。
- 11:30–13:00 停止订阅刷新，保留快照，界面显示「午间休市」。
- 14:57–15:00 收盘集合竞价阶段，分时类预警降级为 P4。

## 收盘复盘模式（15:00 后）

1. 保存当日行情快照（`quotes_cache` 归档 + 当日分时落 `kline_history` 1m）。
2. 统计涨停、炸板、跌停、连板梯队。
3. 汇总大单异动（按档位与方向分布）。
4. 统计龙虎榜新增与变更。
5. 对比观察股票走势（区间涨幅、相对强度）。
6. 记录预警触发结果（触发数、有效率、误报标记）。
7. 生成个股复盘摘要（见 `references/review-report.md`）。
8. 保存用户观察笔记到 `review_notes`。
9. 为下一交易日更新观察池（晋级/降级/移出，需用户确认后落库）。

## 交易日历与异常

- 交易日判定：优先用本地交易日历表/接口，缺失时用「周一至周五且非法定节假日」近似，并在界面标注「日历来源：近似」。
- 临时停牌：`status='suspended'`，该股实时预警静默，详情页显示停牌起始日。
- 代码校验：6 位数字 + 市场后缀；长度、前缀与后缀不匹配（如 `300001.SH`）、已退市代码一律拒绝并提示原因。
- 历史与实时混用：同一图表内混用必须在图例标注分段并给出分界时间，禁止无缝拼接。

## 性能与压测目标

- 单股模式：切股到首屏 < 300ms（有缓存）。
- 多股 12 格：十字光标同步延迟 < 50ms。
- 1000 只订阅：主线程不阻塞，UI 帧率 ≥ 30fps，行情落库批量写入（每批 ≤ 500 条）。
- 预警从数据到达到弹窗 < 300ms（本地链路）。
- 数据库：`kline_history` / `tick_history` 按 symbol 分区索引，逐笔保留期默认 20 个交易日，超期归档 Parquet。
