# 界面规范

## 主题

专业暗色交易终端。所有颜色以 QSS 变量 + `app/ui/theme.py` 常量双份维护，禁止散落硬编码。

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景底 | `#0B0E11` | 全局底 |
| 面板 | `#12161C` | 卡片/侧栏 |
| 面板浮起 | `#1A1F27` | 弹层、选中行 |
| 描边 | `#232A34` | 1px 分割 |
| 主文字 | `#E6EAF0` | |
| 次文字 | `#9AA4B2` | 标签、单位 |
| 弱文字 | `#5C6673` | 禁用、无数据 |
| 上涨 | `#F04438` | 红涨，含量柱 |
| 下跌 | `#12B76A` | 绿跌 |
| 警告 | `#F5B544` | 延时、缺口、降级 |
| 信息 | `#3D8BFD` | 选中、链接 |
| 未知/无数据 | `#5C6673` | 灰，且必须显式写「无数据」 |

字体：数字用等宽（`JetBrains Mono` / `Consolas`）保证对齐；中文用 `Microsoft YaHei UI`。数字列右对齐，价格列固定 2 位小数，涨幅带 `+/-` 与 `%`。

## 布局

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏：市场状态 | 数据源等级+延迟 | 当前时间 | 单股/多股切换 │
├──────────┬───────────────────────────────┬───────────────┤
│ 左栏      │ 中间图表区                     │ 右栏           │
│ 分组树    │ 主图（K线/分时/多股网格）      │ 逐笔成交       │
│ 搜索框    │ 副图（成交量/指标）            │ 大单监控       │
│ 股票列表  │                               │ 概念/龙虎榜    │
├──────────┴───────────────────────────────┴───────────────┤
│ 底栏：预警日志 | 异动记录 | 复盘笔记（Tab 切换）           │
└──────────────────────────────────────────────────────────┘
```

面板可拖动分隔条、可折叠、可恢复默认布局；布局写入 `user_layouts`，`scope=global` 存主窗，`scope=group` 存分组专属布局。

## 顶栏状态

- 市场状态：`集合竞价 / 交易中 / 午间休市 / 已收盘 / 非交易日`
- 数据连接：绿点实时（附 ms）/ 黄点延时 / 红点断开 / 灰点未连接 / 红条纹模拟
- 当前时间：本地时钟 + 与行情时间差（差值 > 5s 显示黄色）

## 图表

- K 线：涨用空心红、跌用实心绿（可切欧美风格，但默认 A 股）；影线与实体同色系。
- 分时：价格线白/浅蓝，均价线黄，昨收虚线灰，涨停/跌停水平线红/绿虚线。
- 成交量柱：按当根 K 线涨跌着色，分时按主动买卖着色（买红卖绿）。
- 逐笔列表：时间、价格、数量、金额、方向箭头（↑红 ↓绿 ·灰）。大单行左侧加色条。
- 多股网格：十字光标竖线跨图同步，每格右上角标注周期与数据等级。
- 事件标记：龙虎榜（旗形）、涨停（实心块）、炸板（空心块）、缺口恢复（浅色阴影带）。
- 无数据：面板居中显示「无数据 / 数据源不支持该方法」，不画假曲线。

## 交互

- 搜索：支持代码、名称、拼音首字母；`Enter` 直接切单股，`Ctrl+Enter` 加入当前分组。
- 键盘：`1–9` 切周期，`F5` 刷新，`Esc` 取消联动选中，`Space` 暂停/恢复自动滚动。
- 拖动股票到分组即移动；`Ctrl` 拖动复制。
- 所有破坏性操作（删分组、批量删股票、清空事件）二次确认并显示影响数量。
- 加载态用骨架条，禁止空白闪烁；长任务显示进度与可取消。

## 可用性底线

- 断线、延时、模拟数据三种状态必须同时在顶栏与相关面板可见，不能只写日志。
- 任何数字为空时显示 `--`，不显示 `0` 或 `0.00`。
- 面向中国用户，单位用「万 / 亿」，不出现英文千分位缩写 K/M/B。
